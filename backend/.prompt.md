# NeuroInfoGrinder Pipeline -- Guide Search & Date/Time Input

## Purpose
This prompt governs the pipeline guide search process and the date/time input improvements in NeuroInfoGrinder.

## Current state
- Pipeline runs 4 stages: RULES -> SIGNAL_SCORING -> LLM_CLASSIFIER -> GUIDE_GENERATION.
- Pipeline trace records have `startedAt`/`finishedAt` (Instant).
- Messages have `messageDate` (Instant).
- Pipeline results endpoint accepts `status` and `from` query parameters, but `from` is currently an Instant parsed from query string -- no user-friendly date/time input.
- Frontend does not have a date/time picker for pipeline filtering.

## Tasks

### 1. Date/time input in pipeline
- Add `from` and `to` query parameters to `PipelineController.getResults()` that accept ISO-8601 date or date-time strings.
- If only a date is provided (e.g. `2026-06-08`), interpret as `2026-06-08T00:00:00Z` for `from` and `2026-06-08T23:59:59.999999999Z` for `to`.
- Add the same filtering to `PipelineController.getQueue()` if applicable.
- Add `from`/`to` filtering to `PipelineTraceService.getTraces()`.

### 2. Frontend date/time picker
- Add a date/time picker component to the pipeline results page.
- The picker should allow selecting either a full date-time or a date only.
- The selected value is sent as ISO-8601 string in the API query.

### 3. Guide search process
- The pipeline already searches for guides by processing messages through the 4 stages.
- When `localGuideFallback=true`, the pipeline falls back to generating a guide from local context if the LLM classifier score is below threshold but above signal threshold.
- The guide search process is initiated by enqueuing messages and running the queue processor.

## How to run the guide search
1. Ensure PostgreSQL is running and migrations are applied.
2. Start the backend: `mvn spring-boot:run` with PostgreSQL env vars.
3. Enqueue messages: `POST /api/v1/pipeline/process-queue?limit=N`
4. Watch events: `GET /api/v1/pipeline/events/stream` (SSE)
5. Check results: `GET /api/v1/pipeline/results`

## Success criteria
- Pipeline results can be filtered by date range with user-friendly input.
- Date-only input works (no time required).
- Full ISO-8601 date-time input also works.
- Guide search runs without H2, using PostgreSQL only.
