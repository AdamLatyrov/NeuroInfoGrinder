# NeuroInfoGrinder — Admin Site Design

## Стек

- **Frontend**: React 18 + TypeScript + Vite
- **UI**: shadcn/ui + Tailwind CSS
- **Графики**: Recharts
- **Data fetching**: TanStack Query (уже в проекте)
- **Routing**: React Router v7 (уже в проекте)
- **Стили**: светлая тема, палитра из текущего styles.css развёрнута в Tailwind tokens

### 1. Dashboard

**Page Header:**
H1: Dashboard
Description: Обзор состояния NeuroInfoGrinder

**Metric Cards (4 карточки в ряд):**

```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│ 3 / 5       │ │ 142         │ │ 47.2K       │ │ 8           │
│ Аккаунты    │ │ В очереди   │ │ Токенов/день│ │ Гайдов/день │
│ ●●●○○ ок   │ ▲ +12 за час │ ▓▓▓▓▓░░ 63%  │ ▼ -2 vs вчера│
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

Каждая карточка:
- Большая цифра (metric)
- Лейбл под цифрой
- Индикатор: статус-точки (аккаунты), дельта (очередь), прогресс-бар (токены), стрелка (гайды)
- Токены: прогресс-бар цвета warning если > 80% лимита, error если > 95%

**Панель «Статус аккаунтов» (половина ширины):**

Таблица 3 колонки: Имя | Статус (Badge) | Последняя активность
Статусы: `success` — подключён, `warning` — ожидает, `error` — отключён
Если есть error-аккаунты — красный алерт-бар над таблицей

**Панель «Последние гайды» (половина ширины):**

Список из 5 строк: Иконка группы | Заголовок гайда | Группа | Время
Клик → переход на страницу гайда

**Панель «Активность за 7 дней» (полная ширина):**

Recharts AreaChart:
- Ось X: дни
- Ось Y: сообщения прочитано (площадь, полупрозрачная заливка accent)
- Линия поверх: гайды найдены (тонкая линия, accent цвет)
- Tooltip: точные цифры при наведении

**Левая панель (280px, ScrollArea):**
- Список групп (из включённых в разделе «Группы»)
- Поиск сверху
- Каждая строка: цветная точка (активная/неактивная) + название + количество сообщений
- Активная группа — подсвечена `accent-bg`

**Правая панель (остаток ширины):**
- Заголовок с названием группы
- Фильтры: тип сообщения (все / обработанные / дали гайд / пропущены)
- Фильтр по дате
- Сообщения — хронологический список

**Сообщение в списке:**

```
┌───────────────────────────────────────────────────┐
│ 👤 Имя   ↩ ReplyTo   10:42                  [⋮]  │
│ Текст сообщения...                                │
│                                    [3 replies ▼]  │
│                                    → Гайд #42     │
└───────────────────────────────────────────────────┘
```

- Бордер слева цветной: серый (не обработано), синий (в очереди), зелёный (дал гайд), жёлтый (пропущен классификатором)
- «↩ ReplyTo» — если это ответ, показывает на кого
- «[3 replies ▼]» — кнопка, раскрывает тред под сообщением
- «→ Гайд #42» — ссылка на найденный гайд (если сообщение привело к гайду)
- [⋮] меню: Просмотреть цепочку, Отправить в обработку, Скопировать ID
