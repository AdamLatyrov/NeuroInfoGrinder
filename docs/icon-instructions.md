# NeuroInfoGrinder — Custom Icon Set Instructions

## Brand Identity

- **Product:** NeuroInfoGrinder — AI-powered guide extraction from Telegram groups
- **Theme:** Dark UI (#0C0E14 background, #161923 cards)
- **Brand colors:**
  - Primary: #5B9BF6 (blue)
  - Accent: #F5C94A (yellow/gold)
  - Success: #34D399 (green)
  - Text: #C5CAD8 (light gray)
- **Style:** Minimal, clean line icons with 1.5-2px stroke, rounded caps, 24x24 viewBox

## Logo Icon (32x32)

- Motif: Neural network — 3 interconnected nodes in a triangular arrangement
- Center node is largest, connected to 2 satellite nodes
- Lines between nodes suggest synapses
- One connection line highlighted in accent gold (#F5C94A)
- Works on both dark (#0C0E14) and light backgrounds
- Must be recognizable at 32px and scalable to 512px

## Delivery Format

- SVG files, 24x24 viewBox (logo: 32x32 viewBox)
- Stroke-based (no fills except for accent highlights)
- Stroke width: 1.5px for 24x24 icons, 2px for 32x32 logo
- strokeLinecap: round
- strokeLinejoin: round
- Color: currentColor (monochrome) with accent elements using #F5C94A
- All icons must pass WCAG contrast on #161923 background (minimum 3:1 for UI components)
- Name convention: nig-{name}.svg (e.g., nig-dashboard.svg, nig-logo.svg)

## Reference

The Cerebrum product (sister brand) uses a similar style — a circular ring mark with accent arc. NeuroInfoGrinder should feel related but distinct: more angular/technical (neural network vs. circular brain).
